--------------------------------------End points (Rest API's)
1. Authentication – /api/auth
Method	Endpoint	Description
POST	/api/auth/register	Register patient
POST	/api/auth/login	Login Admin, Doctor or Patient

2. Admin – /api/admin
Method	Endpoint	Description
POST	/api/admin/doctors	Add doctor
GET	/api/admin/doctors	Get all doctors
PUT	/api/admin/doctors/:id	Update doctor
DELETE	/api/admin/doctors/:id	Delete doctor
GET	/api/admin/patients	Get all patients
PUT	/api/admin/patients/:id	Update patient
DELETE	/api/admin/patients/:id	Delete patient

3. Doctor – /api/doctor
Method	Endpoint	Description
GET	/api/doctor/appointments	View assigned appointments
PATCH	/api/doctor/appointments/:id/complete	Complete appointment and add comments

4. Patient – /api/patient
Method	Endpoint	Description
GET	/api/patient/doctors	View available doctors
POST	/api/patient/appointments	Book appointment
GET	/api/patient/appointments	View own appointments
PUT	/api/patient/appointments/:id	Reschedule appointment
DELETE	/api/patient/appointments/:id	Cancel appointment

Authorization requirements:
- Admin endpoints → ADMIN role
- Doctor endpoints → DOCTOR role
- Patient endpoints → PATIENT role
- Registration and login → Public access

----------------------------------Routers

Why do we use router.use() instead of adding middleware to every API?

Without router.use():
router.get("/doctors", protect, allowRoles("ADMIN"), getDoctors);

router.post("/doctors", protect, allowRoles("ADMIN"), createDoctor);

router.put("/doctors/:id", protect, allowRoles("ADMIN"), updateDoctor);


With router.use():
router.use(protect, allowRoles("ADMIN"));

router.get("/doctors", getDoctors);

router.post("/doctors", createDoctor);

router.put("/doctors/:id", updateDoctor);

An API response is the information backend(Express) sends back to frontend(React).

--------------------AXIOS
Axios is a JavaScript library used to make HTTP requests from React to a backend.

Suppose your .env file contains:
VITE_API_URL=http://localhost:5000/api


When you call:
api.get("/patient/doctors");


Axios combines the base URL and endpoint:
http://localhost:5000/api/patient/doctors

----------------add headers in AXIOS interceptoor
Attach the Authorization header
if (token)
  config.headers.Authorization = `Bearer ${token}`;


First, it checks whether a token exists.

If it exists, Axios adds this HTTP request header:
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...


What is Bearer?

Bearer is an authentication scheme. It indicates that the request is presenting an access token.

Your Express backend reads it using:
const token = req.headers.authorization
  ?.split(" ")[1];


For example:
Authorization: Bearer abc123


Splitting by space produces:
["Bearer", "abc123"]


Index [1] gives the JWT token:
abc123


Then the backend validates it:
jwt.verify(token, process.env.JWT_SECRET);
